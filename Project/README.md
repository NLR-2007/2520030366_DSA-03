## 📌 Project Overview

**Kisaan Krushi AI** is a Java terminal chat assistant for farmers that uses 13 classic Data Structures and Algorithms (KMP, Rabin-Karp, Aho-Corasick, Edit Distance, Suffix Array + LCP, 0/1 Knapsack, Bipartite Matching, Bitmask DP, Max Flow / Min Cut, Greedy Set Cover, Greedy Knapsack, QuickSort, and Parallel Primitives) to diagnose crop diseases, recommend fertilizers under budget, plan crop cultivation, and provide live weather advice.

For full architecture details, source code files, and usage examples, please refer to [**`FarmAssist/README.md`**](./FarmAssist/README.md).
